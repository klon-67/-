# 🎮 GAME MASTER — Telegram Game Bot

**GAME MASTER** — це Telegram-бот з мінііграми, віртуальними монетами, системою досвіду, рівнями, досягненнями та рейтингом гравців. Грай, заробляй нагороди й змагайся з іншими учасниками!

## ✨ Можливості

- 🎲 **Вгадай число** — відгадай число, яке загадав бот. Є три рівні складності: легкий, середній і важкий.
- ✊ **Камінь, ножиці, папір** — грай проти комп'ютера та отримуй нагороди за перемоги.
- 🧠 **Вікторина** — відповідай на запитання з різних тем і заробляй монети та досвід.
- 👤 **Профіль гравця** — переглядай свій рівень, баланс, кількість ігор, перемог і поразок.
- 🪙 **Віртуальні монети** — збирай і накопичуй монети за ігри та щоденні бонуси.
- 🏆 **Рейтинг гравців** — переглядай найкращих гравців за монетами, перемогами та досвідом.
- 🎁 **Щоденний бонус** — отримуй монети та досвід раз на день.
- 🔥 **Серія відвідувань** — збільшуй нагороду за регулярні щоденні входи.
- 📜 **Досягнення** — відкривай нагороди за ігрові успіхи.
- 💾 **База даних SQLite** — зберігай статистику гравців між перезапусками бота.

## 🛠️ Використані технології

- **Python** — мова програмування.
- **python-telegram-bot** — бібліотека для створення Telegram-бота.
- **SQLite3** — база даних для збереження інформації про гравців.
- **Random** — генерація випадкових чисел і вибір ходів комп'ютера.
- **Datetime** — робота з датами та щоденними бонусами.

## 📋 Встановлення

### 1. Встанови Python

Завантаж Python з офіційного сайту:

https://www.python.org/downloads/

Під час встановлення Windows рекомендується поставити галочку **Add Python to PATH**.

### 2. Встанови необхідну бібліотеку

Відкрий термінал у папці проєкту та виконай команду:

```bash
pip install python-telegram-bot
```

SQLite3 та модулі `random` і `datetime` входять до стандартної бібліотеки Python, тому встановлювати їх окремо не потрібно.

### 3. Створи Telegram-бота

1. Відкрий Telegram.
2. Знайди офіційного бота [@BotFather](https://t.me/BotFather).
3. Надішли команду `/newbot`.
4. Вкажи назву та ім'я користувача для свого бота.
5. Скопіюй отриманий токен.

**Важливо:** нікому не передавай токен свого бота.

### 4. Додай токен

Відкрий файл із кодом і знайди рядок:

```python
TOKEN = "ВСТАВ_СЮДИ_СВІЙ_ТОКЕН"
```

Заміни текст усередині лапок на свій справжній токен.

### 5. Запусти бота

Збережи код, наприклад, у файлі `bot.py`, а потім виконай у терміналі:

```bash
python bot.py
```

Якщо все налаштовано правильно, у терміналі з'явиться повідомлення:

```text
🎮 GameMaster запущено!
```

Після цього відкрий свого бота в Telegram і надішли команду `/start`.

## 🎮 Команди бота

| Команда | Опис |
|---|---|
| `/start` | Запустити бота та відкрити головне меню |
| `/help` | Переглянути допомогу |
| `/guess` | Перейти до гри «Вгадай число» |
| `/rps` | Відкрити розділ «Камінь, ножиці, папір» |
| `/quiz` | Відкрити вікторину |
| `/profile` | Переглянути профіль |
| `/top` | Переглянути рейтинг |
| `/daily` | Отримати щоденний бонус |
| `/coins` | Перевірити баланс монет |

## 🪙 Система нагород

Гравці можуть отримувати віртуальні монети та досвід за різні дії.

| Дія | Нагорода |
|---|---|
| Перемога у грі «Вгадай число» | Від 15 до 60 монет залежно від складності, плюс бонус за швидкість |
| Перемога в «Камінь, ножиці, папір» | 15 монет і 15 XP |
| Нічия в «Камінь, ножиці, папір» | 3 монети та 5 XP |
| Правильна відповідь у вікторині | 10 монет і 10 XP |
| Щоденний бонус | Від 50 монет і 5 XP |

За кожні 100 XP гравець отримує наступний рівень. Щоденна серія дозволяє поступово збільшувати розмір бонусу.

**Примітка:** монети є виключно віртуальними ігровими балами та не мають реальної грошової вартості.

## 💾 База даних

Під час запуску програми створюється файл `gamemaster.db`.

У ньому зберігаються:

- ID та ім'я гравця;
- кількість монет і досвіду;
- кількість перемог, поразок та зіграних ігор;
- правильні відповіді у вікторині;
- рекорд у грі «Вгадай число»;
- дата останнього щоденного бонусу;
- серія щоденних відвідувань.

Завдяки SQLite дані залишаються у файлі бази даних після завершення роботи програми.
