# 🎮 GAME MASTER — Telegram-бот

## 📌 Про проєкт

**GAME MASTER** — це Telegram-бот з мінііграми, віртуальними монетами, досвідом, рівнями, профілями та рейтингом гравців.

Гравці можуть розважатися, перевіряти свої знання, заробляти монети та змагатися між собою.

## 🎮 Можливості бота

- 🎲 **Вгадай число** — спробуй відгадати число, яке загадав бот.
- ✊ **Камінь, ножиці, папір** — змагайся з комп'ютером.
- 🧠 **Вікторина** — відповідай на запитання та перевіряй свої знання.
- 👤 **Профіль гравця** — переглядай свої монети, досвід, рівень і статистику.
- 🪙 **Монетки** — перевіряй баланс віртуальних монет.
- 🏆 **Рейтинг** — порівнюй результати з іншими гравцями.
- 🎁 **Щоденний бонус** — отримуй нагороди за активність.
- 📜 **Досягнення** — переглядай ігрові досягнення.
